## 📌 Project Overview
Leon is a responsive, multi-section web template designed for creative agencies. The main goal was to practice translating a professional design concept into clean code without relying on any external frameworks like Bootstrap.

### Key Features:
- 🎨 **Minimalist & Modern Design:** Aesthetic layout with clean spacing and subtle accents.
- 📱 **Section Navigation:** Smooth anchor links connecting top navigation to corresponding sections.
- 🛠️ **Service Showcase:** Well-structured service cards displaying agency competencies.
- 💼 **Portfolio Grid:** Clean project showcase cards.
- 📧 **Contact Integration:** Functional mailto links and direct social media channels.

---

## 🛠️ Tech Stack & Resources
- **HTML5:** Structural markup.
- **CSS3:** Styling, custom layouts, and positioning.
- **Google Fonts:** Custom typography (*Work Sans*).
- **FontAwesome:** Icons for UI elements and social links.
